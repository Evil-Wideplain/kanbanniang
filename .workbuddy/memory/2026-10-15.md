## 突破：GNU 工具链路线可行（无需 VS Build Tools）
- 用户 C++ 环境只用 msys2（clang64），质疑为何 Rust 要 VS → 查明：rustup 默认 target 是 x86_64-pc-windows-msvc（微软 ABI），换 x86_64-pc-windows-gnu（MinGW ABI）即可复用 msys2
- 已安装 `stable-x86_64-pc-windows-gnu` 工具链（rustup，minimal profile，~250MB）
- clang64 提供：cc/clang/ld.lld 链接器、windres、llvm-ar、全部 Windows API 导入库（clang64/lib/lib*.a）、libucrt.a/libmsvcrt.a/libunwind.a
- 缺 libgcc.a / libgcc_eh.a → 建替身库 `~/.cargo/gnu-stubs/`：libgcc_eh.a = libunwind.a 副本，libgcc.a = 空归档（llvm-ar cr）
- 可用构建配方：PATH 加 clang64/bin，RUSTUP_TOOLCHAIN=stable-x86_64-pc-windows-gnu，RUSTFLAGS="-C linker=cc -L C:/Users/XieQi/.cargo/gnu-stubs"，cc crate 自动找到 cc.exe 编译 C build script（brotli/vswhom-sys），embed-resource 自动找到 windres
- hello-world 实测通过（编译 1.2s，运行正常）
